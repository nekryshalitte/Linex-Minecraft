# Linex

**Linex** — современный лаунчер для Minecraft Java Edition под Windows, разработанный **Nekrysha Software** на C# с использованием .NET 8 и WPF.

Linex объединяет управление игровыми версиями, модами, сборками и аккаунтами в одном приложении. Благодаря системе отдельных инстансов можно хранить несколько сборок Minecraft независимо друг от друга, не смешивая моды, настройки и игровые миры.

Поддерживаются Vanilla, Fabric, Forge, NeoForge и OptiFine.

## Возможности

### Игровые инстансы
- Создание отдельных игровых профилей со своими версиями Minecraft и загрузчиками.
- Независимые моды, настройки, конфигурации и миры.
- Быстрое переключение между сборками.
- Создание снимков состояния и откат к предыдущему состоянию.
- Хранение последних пяти снимков.
- Импорт и экспорт инстансов в ZIP.
- Отображение суммарного времени игры.

### Управление модами
- Встроенный поиск модов через Modrinth и CurseForge.
- Установка и удаление модов непосредственно в лаунчере.
- Автоматическая загрузка необходимых зависимостей.
- Импорт Modrinth `.mrpack` и CurseForge `.zip`.
- Поддержка конфигураций, ресурсов и дополнительных файлов модпаков.
- Автоматическая установка наборов оптимизации: Sodium, Embeddium, Lithium, FerriteCore, ModernFix и других.

### Авторизация
- Offline-режим.
- Авторизация через Ely.by с поддержкой скинов.
- Microsoft Authentication через Device Code Flow.
- Сохранение нескольких аккаунтов.
- Быстрое переключение между учётными записями.
- Шифрование данных авторизации через Windows DPAPI.

### Игровое окружение
- Автоматическая загрузка Java 8, 17 и 21.
- Автоматическая установка необходимых библиотек, ассетов и загрузчиков.
- Проверка целостности игровых файлов по SHA-1.
- Автоматическое восстановление повреждённых файлов.
- Автоматический подбор оперативной памяти.
- Оптимизированные JVM-флаги с возможностью ручной настройки.
- Встроенный BetterF3 с собственными пресетами оформления.
- Анализ причин аварийного завершения Minecraft.

### Интерфейс
- Тёмная и светлая темы оформления.
- Единый визуальный стиль всех основных окон.
- Отдельные окна управления модами, инстансами и аккаунтами.
- Отображение головы игрового персонажа.
- Быстрый доступ к папкам Java и скриншотов.

### Безопасность
- Шифрование токенов Ely.by, Microsoft и ключа CurseForge через Windows DPAPI.
- Проверка SHA-256 установщика перед запуском обновления.
- Использование HTTPS для загрузок.
- Проверка разрешённых источников файлов.
- Защита от Path Traversal и Zip Bomb при импорте модпаков.
- Проверка установщиков Forge и NeoForge.
- Защита конфигурации от повреждения.

### Автоматические обновления
- Проверка новых версий через GitHub Releases.
- Автоматическое скачивание установщика.
- Проверка контрольной суммы SHA-256.
- Обновление поверх существующей установки.
- Сохранение игровых данных и пользовательских настроек.

## Установка

Для установки используется отдельный установщик `Linex.Installer.exe`.

Возможности установщика:
- Выбор папки установки.
- Создание ярлыков на рабочем столе и в меню «Пуск».
- Автоматическое определение существующей установки.
- Обновление без удаления пользовательских данных.
- Автоматическая установка .NET 8 при необходимости.

При удалении можно выбрать, сохранить папку `data` или удалить её вместе с лаунчером.

**Официальный сайт:** https://linex.xo.je

## Хранение данных

Все пользовательские и игровые данные располагаются в папке `data` рядом с исполняемым файлом лаунчера.
Linex не использует `%APPDATA%` для хранения игровых данных. Реестр Windows используется только для регистрации приложения в списке установленных программ.
