# Linex

Linex — лаунчер для Minecraft (Vanilla / Fabric / Forge / NeoForge / OptiFine) с отдельным установщиком. Разработан **Nekrysha Software**, написан на C# (.NET 8, WPF).

Часть данных (новости, конфигурация, списки модов для раздела «Оптимизация») лаунчер получает с собственных серверов Nekrysha Software.

Готовый установщик (`Linex.Installer.exe`) распространяется отдельно, собранные бинарники (`bin/`, `obj/`, `publish/`) в репозиторий не включены — см. `.gitignore`.

## Возможности

- Запуск Vanilla, Fabric, Forge, NeoForge, OptiFine — все нужные библиотеки, ассеты и загрузчики скачиваются автоматически.
- Встроенный раздел «Моды»: поиск по Modrinth и CurseForge с пагинацией, установка/удаление модов без выхода из лаунчера.
- Кнопка «Оптимизация» — автоматическая установка пакета модов (Sodium/Embeddium, Lithium, FerriteCore, ModernFix и т.д.) под нужный загрузчик.
- Автоподбор объёма памяти под игру (не больше 60% ОЗУ) и готовые оптимизированные флаги JVM; можно переопределить вручную.
- Better F3 — всегда ставится и включается автоматически, со своими цветовыми пресетами (минимальный/расширенный) под Forge/NeoForge (toml) и Fabric (json).
- Вход через Ely.by (Yggdrasil API + authlib-injector) — скины и совместимость с серверами Ely.by; есть и офлайн-режим.
- Поиск Java нужной версии: сначала путь из настроек, затем `data\runtime`, `JAVA_HOME`, `PATH`.
- Все файлы (версии, библиотеки, моды, миры, настройки, логи) хранятся только в папке `data` рядом с exe — ничего не пишется в `%APPDATA%` или реестр (кроме записи об установке для деинсталлятора).
- Деинсталлятор: закрывает запущенный лаунчер, удаляет ярлыки и запись в списке программ Windows, данные (`data`) можно оставить или удалить по выбору.

## Как работает лаунчер

1. **Запуск.** Показывается заставка, подгружаются настройки и новости, лаунчер проверяет список версий Minecraft.
2. **Выбор сборки.** Пользователь выбирает версию игры и загрузчик модов (Vanilla, Fabric, Forge, NeoForge или OptiFine).
3. **Авторизация.** Либо офлайн-режим (просто ник), либо вход через Ely.by — со скинами и доступом к серверам Ely.by (поддерживается и двухфакторная защита).
4. **Скачивание.** При первом запуске выбранной версии лаунчер сам докачивает клиент, библиотеки, ассеты, нужный загрузчик модов и, если требуется, подходящую Java — всё складывается в папку рядом с лаунчером, ничего не пишется в системные папки.
5. **Моды.** Прямо в лаунчере есть поиск модов на Modrinth и CurseForge — можно поставить/удалить мод в пару кликов. Для удобного дебаг-экрана (F3) автоматически ставится и настраивается Better F3 в фирменном стиле.
6. **Оптимизация.** Отдельной кнопкой ставится готовый набор модов на производительность (Sodium/Embeddium, Lithium, FerriteCore, ModernFix и др.), а память под игру лаунчер подбирает автоматически (но её, как и флаги JVM, можно задать вручную).
7. **Запуск игры.** Лаунчер собирает все нужные аргументы и запускает Minecraft; по желанию сам закрывается после старта игры.
8. **Удаление.** Отдельный пункт в «Параметры → Приложения» Windows — можно удалить только лаунчер или лаунчер вместе со всеми данными (мирами, модами, настройками).

Установщик (`Linex.Installer.exe`) — отдельная программа: ставит лаунчер в выбранную папку, создаёт ярлыки на рабочем столе и в «Пуск», а при повторном запуске сам находит уже установленную версию и обновляет её, не трогая сохранённые данные.
